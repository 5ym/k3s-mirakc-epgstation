# これから

やると決めたもの。**入ったものはそれぞれの文書へ移してあります** —
決めた理由と、やってみて外れた読みは移した先に残してあるので、
「なぜこうなっているか」はそちらで読めます。

## ライブ視聴の残り

**映像と音声 (第1段階) は入りました** — 画面も焼き方も遅延の詰め方も
[stream.md](stream.md) に移してあります。残っているのはこの3つ。

- **字幕** (第2段階) — 2本目の ffmpeg を足してサイドチャネルへ流し、canvas に重ねる。
  録画側の実装をそのまま使えるので、変わるのは出口だけ。**セッションごとに ffmpeg が
  1本増える**ので、実費を測ってから入れる
- **データ放送** (第3段階) — psisiarc → web-bml をサイドカーとして起動し、iframe で抱える
- **低遅延の追い込み** (任意) — WebRTC/WHEP か Media over QUIC。いまは 0.5 秒前後

## 実機で確かめられていないもの

- **`px4_drv` の chardev での選局。** 書いてはあるが、ここに chardev のデバイスが
  1つも無いので当てられていない (値は `px4_drv` と `recisdb` から取った)
- 実際の放送で ARIB の文字符号がどこまで読めるか (外字の取りこぼし)
- **CM検出の精度を数で言えるところまで見ていない。** 個々の録画では追えているが
  (合致率・CM の割合・落ちたときの理由)、何本中何本が正しく切れたかは数えていない
- `logoframe` がロゴを覚えるのに要る尺 (事前学習は5分で掴んでいるが、下限は未測)
- Mac の `denpa://` 登録 (アプレットの組み立てと `lsregister`)
