# EPGStation からの引き継ぎ

**録画・ルール・手動予約を、EPGStation から denpa へ移します。** 設定画面から
実行するもので、**何度走らせても同じ結果になります** (取り込み済みは飛ばす)。

| 探しもの | 見る場所 |
| --- | --- |
| 全体像 | [architecture.md](architecture.md) |
| 環境変数の一覧 | [app.md](app.md) |
| 保存先の形 | [library.md](library.md) |

## 先に用意するもの

**2つ見えるようにします。** どちらかが欠けていると実行できません。

| 何を | どうやって |
| --- | --- |
| **EPGStation の録画置き場** | その PVC (かディレクトリ) を denpa の Pod に**マウント**する |
| **EPGStation の MariaDB** | denpa から届くところに置く。読むだけです |

**録画置き場が見えていないと、設定画面はボタンごと出しません** (`migrate.available`)。
「引き継ぎ元 ○○ が見えません」と出ているなら、まだマウントできていません。

`k3s/` にも `compose.prod.yml` にも**雛形は入っていません。** 引き継ぎは1回きりで、
済んだら外すものなので、手元の EPGStation に合わせて足してください。

| 変数 | 既定値 | |
| --- | --- | --- |
| `EPGSTATION_RECORDED_DIR` | `/epgstation-recorded` | 録画置き場を denpa 側にマウントした場所 |
| `EPGSTATION_DB_HOST` | `db` | |
| `EPGSTATION_DB_PORT` | `3306` | |
| `EPGSTATION_DB_USER` | `root` | |
| `EPGSTATION_DB_PASSWORD` | `epgstation` | |
| `EPGSTATION_DB_NAME` | `epgstation` | |

> **EPGStation v2 のテーブル構成を読みます** (`recorded` / `rule` / `reserve`)。
> v1 は見ていません。

## やり方

**先に番組表を集めておきます。** 手動予約は「その番組が denpa の番組表にあること」が
条件なので、空のまま走らせると予約だけ入りません (下記)。

1. `/settings` の **「EPGStation からの引き継ぎ」**
2. **「実際に取り込む」を外したまま実行する** — 何が入るかを出すだけで、ファイルも
   データベースも触りません。件数と、飛ばされるものの理由がログに出ます
3. 中身を見て問題なければ、**「実際に取り込む」を入れて**もう一度実行する

進み具合はそのカードの中に出ます (画面へ push されるので、開いたままで見えます)。
**数百GBのコピーになるので、リクエストの中では終わりません。** 開始だけ受けて裏で
進みます。

**既定はコピーです。** 元をそのまま残すので、中身を確かめてから EPGStation 側を
消せます。**空き容量が足りないときだけ「コピーではなく移動する」**を入れてください。

## 何が入って、何が入らないか

**順番はルール → 手動予約 → 録画**です。録画のコピーがいちばん長いので、先に
ルールと予約を済ませておけば、**途中で止めても予約は動き出します。**

### ルール (`rule`)

キーワード・除外キーワード・**キーワードを当てる範囲**・種別 (GR/BS/CS/SKY)・
チャンネル・ジャンル・有効かを移します。名前はキーワードをそのまま使い、
キーワードが空なら `EPGStation #<id>` になります。

当てる範囲 (番組名・説明・詳細) も向こうから引き継ぎます。denpa の既定に寄せると、
説明まで見ていたルールが**黙って当たらなくなる**ためです。

- **時刻指定のルールは入りません。** denpa に当たるものがありません
- **キーワードもチャンネルもジャンルも空のルール**は飛ばします (全番組に当たるため)

> **焼き方は移しません。** コーデックもCMの扱いも denpa では全体設定で、ルールには
> 持たせていません ([library.md](library.md))。引き継いだあとに `/settings` で
> 決め直してください。

### 手動予約 (`reserve`)

**ルールから作られたものは移しません** (`ruleId IS NULL` のものだけ)。ルールを
移してあるので、denpa 側が自分で作り直します。除外印 (`isSkip`) の付いたものと、
**もう終わっている番組**も飛ばします。

**denpa の番組表にその番組が無いと入りません。** 番組表を集める前に走らせると
「番組表に無いので取り込めません」が並びます。**番組表が埋まってからもう一度
実行すれば入ります** (何度走らせても平気です)。

### 録画 (`recorded`)

**エンコード済みがあればそちらを優先**して取ります。

**置き場は「denpa 自身が録ったとき」と同じに揃えます。** EPGStation の
`video_file.type` が `encoded` かどうかで分かれます。

| 向こうの型 | 置く先 | |
| --- | --- | --- |
| `encoded` | **保存先** (`LIBRARY_DIR`) | 完成品として扱う。`.nfo` とサムネイルも作る |
| それ以外 (生TS) | **作業領域** (`RECORDED_DIR`) | denpa 側で**焼き直せる**状態になる |

生TSを保存先に置くと denpa からは「エンコード済み」に見えてしまい、**録り直せず、
Kodi にも巨大な MPEG-2 が並びます。** サイドカー (`.nfo`・サムネイル) を作るのも
保存先に置いたものだけです — 作業領域は Kodi から見えません。

- **元のパスは3通りで探します。** EPGStation が相対で持っていることも絶対で持って
  いることもあるためです。それでも見つからないものは `missing` として数え、
  ログに残します (**行だけ作ることはしません**)
- **取り込み済みは飛ばします。** EPGStation 側の ID の符号を反転したものを
  `program_id` に入れてあるので、denpa の番組IDと衝突せず、途中で止めて再開しても
  二重に入りません (ルールと手動予約のほうは `source` に `epgstation:<id>` を持ちます)

## 済んだら

**マウントと `EPGSTATION_*` を外します。** 引き継ぎが済めば要らないもので、
残しておくと設定画面にボタンが出たままになります。

元の PVC を消すのは、**denpa 側で中身を確かめてから**にしてください
(コピーで取り込んだ場合、消すまでは EPGStation もそのまま動きます)。
